# Лабораторная 4 — кассы вокзала: синхронизация процессов

Несколько касс продают и возвращают билеты на одни и те же 5 поездов по 50 мест. Каждая касса — отдельный
процесс. Места лежат в общей памяти (Boost.Interprocess), каждая касса ведёт свой журнал проданных билетов.
После работы программа сверяет места с журналами.

**В стартовом коде кассы никак не синхронизированы** — одно место продаётся дважды. Ваша задача — это исправить.

```
./build/station --run --offices 4 --seconds 3   # 4 кассы, 3 секунды, сверка
./build/station --check                         # сверка ещё раз
```

`--office --id K --seconds N` — одна касса; так её запускает `--run`, вручную обычно не нужно.

Итог выглядит так (код возврата 0 — сверка сошлась, 3 — нет, 4 — касса упала или зависла):

```
Касс: 4, время: 3.01 с, операций: 2009823, в секунду: 668783
По журналам касс продано: 83, занято мест в поездах: 74 — ОШИБКА
  поезд 1, место 8: продано кассами 3 и 4, в поезде записана касса 3
  поезд 2, место 8: билет у кассы 2, а место свободно
  поезд 2, место 9: продано кассами 2 и 4, в поезде записана касса 4
```

Программа создаёт в текущем каталоге папку `sales/` с журналами касс — запускайте из любого удобного каталога.

## Boost

Нужен Boost 1.80 или новее. Boost.Interprocess — только заголовки, собирать Boost не нужно.

| ОС | Установка |
|----|-----------|
| Windows | `vcpkg install boost-interprocess`, CMake запускать с `-DCMAKE_TOOLCHAIN_FILE=<vcpkg>/scripts/buildsystems/vcpkg.cmake` |
| macOS | `brew install boost` |
| Ubuntu | `sudo apt install libboost-dev` |

Сборка:

```
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

Нужен компилятор с C++20 (GCC 13+, Clang 17+, MSVC 19.29+) и CMake 3.20+. На Windows с Visual Studio бинарник
окажется в `build/Release/station.exe`.

## Устройство

| Файл | Что внутри | Менять? |
|------|------------|---------|
| `main.cpp` | Разбор аргументов, **цикл кассы** (`RunOffice`), запуск касс и печать итога (`RunStation`) | да |
| `station.h/.cpp` | `Station` — поезда и места; `SharedStation` создаёт и открывает общую память `"station"` | нет |
| `journal.h/.cpp` | `Journal` — билеты кассы и её файл `sales/office-K.txt` | нет |
| `spawn.h/.cpp` | `RunOffices` — запускает кассы отдельными процессами, ждёт, убивает зависшие | нет |
| `check.h/.cpp` | `CheckStation` — сверка мест с журналами | нет |

Операция кассы — между комментариями «от сих» и «до сих» в `RunOffice`:

- **продажа**: случайный поезд → первое свободное место → билет в журнал → номер кассы в место;
- **возврат**: случайный свой билет → освободить место (если оно ещё за нами) → убрать билет из журнала.

Чем больше у кассы билетов, тем чаще она возвращает, — в среднем у каждой около 20 билетов.
Кассы нумеруются с 1; `0` в месте означает «свободно».
